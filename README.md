# Relay releases

Installers and update files for the Relay desktop app. Relay's source code lives elsewhere; this repository holds only built releases.

Download Relay at [www.tryrelay.sh/download](https://www.tryrelay.sh/download).

- macOS: `Relay-mac-arm64.dmg` (Apple silicon) or `Relay-mac-x64.dmg` (Intel)
- Windows: `Relay-windows-x64.exe`
- Linux: `Relay-linux-x86_64.AppImage`

Installed apps update themselves from the releases here.
